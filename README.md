##Sales Data Analysis Using SQL
## Project Overview
This project focuses on analysing sales performance, product performance, and customer purchasing behaviour using SQL. The analysis uses three relational tables: Sales, Products, and Customers, to extract meaningful business insights and support data-driven decision-making.
## Project Objectives
- Analyse overall sales performance.
- Identify top-performing products.
- Understand customer purchasing behaviour.
- Explore sales trends and patterns.
- Answer business questions using SQL queries.
## Dataset Description
The project uses three tables:
- Sales: Contains sales transaction data.
- Products: Contains product-related information.
- Customers: Contains customer-related information.
